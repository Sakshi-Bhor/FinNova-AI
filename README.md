# 🚀 FinNova AI — Smart Currency Converter Dashboard

FinNova AI is a modern, fully responsive **currency converter dashboard** with AI assistance, real-time exchange rates, history tracking, and a premium UI experience.

---

## 🌟 Features

### 💱 Currency Converter

* Convert between **all global currencies**
* Real-time exchange rates via API
* Instant flag updates based on selected currency
* Swap currencies with one click

### 📊 Dashboard

* Clean financial overview
* Interactive chart (weekly trend visualization)

### 📜 History Tracking

* Automatically stores recent conversions
* Easy to review previous calculations

### ⭐ Favorites

* Predefined popular currency pairs
* Quick reference section

### 🤖 AI Assist (Basic Smart Bot)

* Answers finance-related queries like:

  * Currency insights
  * Gold trends
  * Inflation basics
  * Crypto overview

### 🎨 Theme System (Pro)

* Dark Mode 🌙
* Light Mode ☀️
* Neon Mode 💜
* Gold Luxury Mode 🏆

### 🌌 Animated Background

* Floating gradient orbs
* Smooth & lightweight animation
* Fully responsive

### 📱 Fully Responsive

* Works on:

  * Desktop 💻
  * Tablet 📱
  * Mobile 📲
